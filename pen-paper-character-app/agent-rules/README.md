# Agent Rules

Task-scoped rules for AI agents (Antigravity, Claude Code, Claude.ai,
Cursor). Read the file(s) matching your task type — not the whole
folder.

Cline has its own detailed rulebook in `.clinerules/` (local-only, not
in git). **If you are not Cline, do not look for `.clinerules/` — you
will not find it.**

## How to use

1. Always read `shared.md` first.
2. Read **one** file matching your task type.
3. Read `verification.md` before reporting done.

That is 3 files max, ~150 lines, per task.

## Task index

| Task type | Also read |
|---|---|
| API route change | `api.md` |
| React component / UI work | `components.md` |
| State / hooks / sync effects | `state.md` |
| Library / FK / rename dialog | `library.md` |
| Prisma schema change | `prisma.md` |
| Before reporting done | `verification.md` |

## What this folder is not

- Not a duplicate of `AGENTS.md`. Universal taboos live there.
- Not a duplicate of `.clinerules/`. Cline has its own, more detailed
  rulebook.
- Not a step-by-step tutorial. It is a rules digest for agents that
  only need the relevant slice.
